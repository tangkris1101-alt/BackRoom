# Third-party assets

All third-party files are bundled locally. The game performs no runtime requests to these sources.

## Textures

- `Rock027` by ambientCG, CC0 1.0: https://ambientcg.com/view?id=Rock027
- `Long White Tiles` by Jenelle van Heerden and Sergej Majboroda, CC0 1.0: https://polyhaven.com/a/long_white_tiles
- `Concrete Floor Worn 001` by Dimitrios Savva and Rico Cilliers, CC0 1.0: https://polyhaven.com/a/concrete_floor_worn_001
- `Ground 030` by ambientCG, CC0 1.0: https://ambientcg.com/view?id=Ground030
- `Weathered Brown Planks` by Dimitrios Savva and Rico Cilliers, CC0 1.0: https://polyhaven.com/a/weathered_brown_planks
- `Box Profile Metal Sheet` by Amal Kumar, CC0 1.0: https://polyhaven.com/a/box_profile_metal_sheet
- `Asphalt 02` by Rob Tuytel, CC0 1.0: https://polyhaven.com/a/asphalt_02
- `Pavement 04` by Jan Burghardt, CC0 1.0: https://polyhaven.com/a/pavement_04
- `Red Brick 03` by Rob Tuytel, CC0 1.0: https://polyhaven.com/a/red_brick_03
- `Concrete Wall 006` by Charlotte Baglioni and Dario Barresi, CC0 1.0: https://polyhaven.com/a/concrete_wall_006

The Level 10/11 derivatives are 768 px JPEGs created from the official 1K downloads. Exact paths, dimensions, sizes, and SHA-256 values are recorded in `src/assets/textures/LEVEL_10_11_ASSET_MANIFEST.md`.

## Visual reference

- `Smiler (Backrooms)` by Edward Johnson 3 / lucaarcadu, CC BY 4.0: https://sketchfab.com/3d-models/smiler-backrooms-ea10d7f4750341f0ada6a12a6530014a

  The downloadable archive requires an authenticated Sketchfab session, so the game uses an original optimized local mesh while preserving the credited model as its visual reference.
