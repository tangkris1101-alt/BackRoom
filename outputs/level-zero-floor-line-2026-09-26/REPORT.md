# Level 0 地面分界线（颜色差异）修复与截图复检

日期：2026-09-26

## 结论（2026-09-26 更新）

地面那条贯穿视野的直线，根因是 **分区贴花**（`addFloorTint`）：每个 `DARK_ZONES` / `BRIGHT_ZONES` 分区在地面上方 1.8/2.2 cm 处铺一张 `PlaneGeometry` 贴花，材质是 **不参与光照的 `MeshBasicMaterial`**。它是一块"恒定亮度"的叠加色块——无论先把 alpha 羽化还是改成径向渐隐，它的**大面积平铺 + 轮廓**都会读成一条分界线。

玩家用调试面板逐层排除后确认：**关闭"分区贴花"后分界线完全消失**（截图 `before-*` 两张即为 ON/OFF 对照）。

因此最终处理是**移除贴花层**：分区情绪保留在烘焙光场的软椭圆盖章里（暗 6.2% / 亮 2.2%），那条线随之消失。

## 改动（最终）

`src/scene/level-zero/world.js`

- 删除 `addMoodZones` 与 `createZoneTintAlphaMap`（贴花平面及其软边 alpha 一并移除）。

`src/scene/level-zero/index.js`

- 移除 `addMoodZones` 的导入与调用，以及调试开关里的 `分区贴花` 一项；
- 保留光场的分区软椭圆盖章（`DARK_ZONES` / `BRIGHT_ZONES`，椭圆 + 长尾衰减）。

保留的两处软化改进（仍然有效）：

- 光场眩光经**羽化掩膜**受限（不再用整格矩形 `clip()`）；
- 光场分区为**软椭圆**而非矩形。

## 改动（两轮）

**第一轮 —— 先把硬边羽化**

- 光场分层：光晕画在独立图层，可达格子改为生成**掩膜**，掩膜 `blur(8px)`（512² 上约 2 m）后用 `destination-in` 施加。光照仍只落在可达区域（不穿墙），台阶边变渐变。
- `createZoneTintAlphaMap()`：给分区贴花加软边 `alphaMap`（第二轮改为径向渐隐，最终随贴花一起移除）。
- `scripts/check-realism-systems.mjs`：断言从"必须存在 `context.clip()`"改为"光晕必须经羽化掩膜受限"（约束意图不变）。

**第二轮 —— 换掉矩形形状**（玩家反馈"还是有"）

羽化只降低锐度，**矩形形状本身**仍在：大面积 + 直边色调差依旧读得出边界。这一轮改形状：

- 光场分区盖章：`fillRect` 矩形 → **软椭圆**（`translate/scale` + 径向渐变，中心 50% 满强度，边缘长尾到 0），强度不变（暗 6.2%、亮 2.2%）；
- 分区贴花 alpha：矩形边羽化 → **径向渐隐**（中心平台 + 圆弧边）。

**第三轮 —— 定位并移除真正的元凶**（玩家用调试面板逐层排除）

- 玩家反馈：关闭"分区贴花"后分界线完全消失 → 贴花（不参与光照的 `MeshBasicMaterial` 叠加平面）就是那条线本身；
- 处理：**删除贴花层**（`addMoodZones` / `createZoneTintAlphaMap` 一并移除），分区情绪由光场软椭圆盖章承载。

## 证据边界

- **未能复现玩家截图的同一机位**：本地无头浏览器无法自由转视角（pointer lock 不可用，触屏拖拽在无头下 `setPointerCapture` 失败），只能验证出生点与沿走廊前进两类机位。因此结论建立在"机制 + 光场量测 + 上述机位实机画面"上，而不是同位置前后对比。
- 若该处仍有分界，剩下三类可能来源需要玩家机位才能继续定位：
  1. **阴影**：`realism-indoor-shadow-key` 聚光灯（跟随最近灯具）把墙/柱投到地面，本身就是直边暗区；本地复刻 A/B 未出现直线，但真实管线还含锥角、距离与后期处理差异。
  2. **后期处理**：GTAO / 暗角 / 颗粒。
  3. **墙脚阴影贴图噪点**：玩家上一张截图里，墙与地毯交界呈虚线状锯齿（典型 shadow acne），与地面分界不是一回事，但同样会被读成"线"。

## 范围

- 只改 Level 0 的烘焙光场分层方式、分区形状与分区贴花边缘；地毯纹理、宏观磨损层、灯光布局、房间与小桌道具均未改动。
- 分区强度保持原值（光场 6% / 2%，贴花 3.5% / 5.5%）。
