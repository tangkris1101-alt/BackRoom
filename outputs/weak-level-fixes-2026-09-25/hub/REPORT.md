# THE HUB 偏弱材质修复验收

- 原问题：沥青与混凝土大面几乎纯色，近处黑位压死；拱顶没有 UV，因此无法呈现微表面纹理。
- 本次修改：在 `src/scene/hub/` 内复用项目已有沥青、混凝土与磨损地面 PBR 贴图；按世界尺度铺设地面、步道、墙体与拱顶 UV；为拱顶加入受漫反射纹理调制的微弱自发光以模拟间接反射，并略微调整环境光与灯具覆盖。保留暖色、昏暗的隧道氛围。
- [修前截图](before.jpg) · [修后截图](after.jpg)。均为本地 Vite 真实游戏场景，`app.html?debug=true&level=-1`，1280×720，默认出生点，开始游戏后按 `X`，并确认 `#scene[data-debug-features="false"]`。
- 目视结果：近处沥青裂纹与颗粒、侧墙污渍、拱顶纹理已可辨认；远处仍有雾化与暗部，属于该层级刻意保留的隧道氛围。
- 验证：`npm.cmd run check` 通过；浏览器控制台无 warning/error。统一生产构建与构建版截图由主代理执行。
