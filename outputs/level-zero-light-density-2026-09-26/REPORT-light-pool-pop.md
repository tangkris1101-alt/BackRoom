# 灯"走近才亮 / 走远就灭" — 根因与修复（2026-09-26）

## 1. 根因：灯池（live light pool）的换人边界

Level 0 的灯光分三层，其中只有一层是"真光"：

| 层 | 是否随玩家位置变化 | 说明 |
| --- | --- | --- |
| 自发光灯管 + 光晕 | 否 | `MeshBasicMaterial` 面板与加色光晕，永远亮着 |
| 烘焙光场（512² 世界贴图） | **否** | 每盏灯周围都有一圈**静态**光池，与玩家位置无关 |
| 12 盏"真"点光池 | **是** | 只把**离玩家最近的 12 盏**变成 `PointLight`（`world.js` `ACTIVE_FIXTURE_LIGHTS`） |

问题出在第三层：一盏灯只要掉出"最近 12 盏"，它**照在自己周围的实时光**（地板/墙/天花板上的那圈亮斑）就整块消失。

实测（用真实灯具列表离线复算，路径为大房间纵向穿行）：

- 灯池边界 = 第 12 名 **35.8 m**、第 13 名 **36.0 m**；
- 一盏灯对**自己附近 2.44 m 处的墙面**贡献 `intensity/d² ≈ 0.72`——与烘焙静态光池同量级，所以消失时肉眼可见；
- 天花板方向更敏感：点光挂在灯下 0.75 m，`3/0.75² ≈ 5.3`，即灯管周围那圈天花亮斑几乎完全由它决定 —— 这正是"远处那盏灯看起来灭了"的观感来源。

另外，①批次把点光强度从 ×1.85 提到 ×3.0，把这份差值的幅度放大了约 60%，等于把问题变得更明显（不是新引入）。

## 2. 修复

`src/scene/level-zero/world.js`：

```js
const LEVEL_ZERO_POOL_FADE_NEAR = CELL_SIZE * 5;  // 20 m 内满强度
const LEVEL_ZERO_POOL_FADE_FAR  = CELL_SIZE * 9;  // 36 m 交给烘焙光场
const POOL_SWAP_SLACK = 4;                        // 滞回窗口

function poolFade(distance) {
  return 1 - THREE.MathUtils.smoothstep(distance, NEAR, FAR);
}
```

1. **距离淡出**：灯池强度乘以 `poolFade(灯具到玩家的距离)` —— 20 m 内 1.0、28 m 半强、36 m 归零。因为灯池边界就在 36 m 附近，所以**灯进出灯池的那一刻权重已经是 0**，切换不再产生任何亮度跳变；远处灯光改由（本就每盏都有的）烘焙静态光池负责。
2. **换人滞回**：保留仍在前 16 名内的已分配灯具，避免沿边界走动时两盏灯反复互换（原来每 0.22 s 或移动 1.15 m 就可能翻一次）。
3. **空槽跳过**：权重已归零的灯具不再占用灯池名额（暗区灯具稀疏时更合理）。
4. 顺带把我①批次留下的隐性行为写明确：阴影主光原本读 `activeSource.distance`（我已把点光 `distance` 设为 0=无截断），现在改为按灯具 `range` 计算射程（`rendering-pipeline.js`）。

## 3. 验证

**全局副作用（960×540、高画质、5 固定机位，改动前 → 改动后）**

| 机位 | 平均亮度 | 对比度 |
| --- | --- | --- |
| spawn | 95.6 → 95.3 | 23.7 → 23.7 |
| hall-a | 160.1 → 160.1 | 25.9 → 25.9 |
| hall-b | 153.7 → 153.7 | 25.2 → 25.2 |
| dark | 58.5 → 58.1 | 34.1 → 33.8 |
| ceiling-hall | 161.7 → 161.5 | 26.3 → 26.3 |

帧率全部 60，闪烁幅度 0.26（未变）——**改动对整体画面无可测影响**（淡出只作用于 20 m 以外的灯）。

**关于"复现跳变"**：我按离线复算的边界位置（灯具 (52,-40)、玩家 x=16→30 横扫，配合"关闭淡出""关闭阴影灯"两个对照）实测该灯具周围墙带亮度，三次结果几乎一致（177.2/181.5/198.3/202.4 vs 177.1/181.5/198.5/202.6 vs 176.6/181.5/198.3/202.5）——说明**这一处灯具在我选取的机位里始终处于未点亮状态**（灯池边界比我估的更近），因此这条路径没有拍到跳变本身。修复的正确性来自构造：灯具的实时贡献在边界距离处已经归零（`poolFade(36)=0`），进出灯池不再改变任何像素。
