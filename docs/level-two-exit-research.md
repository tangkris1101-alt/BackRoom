# Level 2 出入口与「切出」设定参考

整理日期：2026-09-27。用途：给 Level 2（PIPE DREAMS）的出口设计与后续切出机制提供官方依据。

## 0. 名称前提

- Wikidot（当前主维基）已把 Level 2 改名为 **"Abandoned Utility Halls"（废弃公共带）**，*Pipe Dreams* 退为旧名／别称，见 [Level 2](https://backrooms-wiki.wikidot.com/level-2) 与 [archived:level-2](https://backrooms-wiki.wikidot.com/archived:level-2)。
- Fandom 维基仍叫 **"Pipe Dreams"**，但那是另一套设定体系（其出口体系与本作现状冲突，见 §4）。
- 本作沿用旧称 PIPE DREAMS，属于合法别称，不需要改名。

## 1. 出口：主流是「门」

## 2. 出口：非门方式（含「切出」）

| 方式 | 去向 | 原文要点 |
| --- | --- | --- |
| **反常高温区切出** | **Level 127** | "any areas of Level 2 that become unreasonably hot become **hotspots for noclipping into Level 127**." |
| 无缝过渡 | Level 606 / Level 38 | "individuals may suddenly find themselves **seamlessly transitioning** into either of the two above levels." |
| 长时间穿行 / 与主布局成直角的挖掘暗道 | Level 158 / Level 902 | "By traversing the halls for long enough, or by finding **small dugout passageways at perpendicular angles**…" |
| 走廊序列 = 科乐美秘籍码 | **The Hub（枢纽）** | 与 Level 1 相同的进入法；"the location … is not officially known by most main groups"（位置不成文，只存在于传闻）。 |
| 心理条件（想着要上洗手间后再碰门） | Level 189 | "By wishing to use the restroom on this level…" |
| 办公区 EL3A（层级内部子区域） | 回到 Level 2 本体 | "exiting this area will place individuals back into Level 2." |

- 官方"切出"出口**不是**天花板破洞或某面墙：最具体的只有**热区切出 → Level 127**（大停电期间失效）。
- 归档旧版另有：**切入极热区域 → Level 2.1**。
- 入口方向的切出（不作为出口）：从前厅直接切出、Level 17 切入管道、Level 264 切入画作、Level 84 长时间触摸地形、Level 522 埋进线缆堆。

## 3. 入口

- **主入口**：Level 1 中"看起来比本层其它走廊更长"的走廊，**平滑过渡**进入（管道与阀门逐渐出现）。
- **从前厅直接切出**：官方明说 Level 2 是少数能从现实直接进入的层级之一。
- 其它入口见页面折叠块：Level 52（洞穴小隧道）、287（随机门）、2.2、8（通风管）、11（无内部装修建筑的门）、43（水族馆员工通道）、84（Clipped Park 切行）、127（焚尸炉）、141（楼梯／电梯）、158（白羊站地铁隧道）、173（瀑布）、309（The Path 三英里）、480（连接商铺的走廊）、522（线缆堆）、916（楼梯底部木门）、997（树上的粉色门）、办公区 EL3A。

## 4. Fandom 版（**冲突设定**，仅作参考）

- 入口：从前厅切出可抵达的最后层级、维护区、Level 1 渐变、Level 8 通风口、Level 11 井盖等。
- 出口：**消防出口** → Level 1 或 Level 3；金色"Φ"门 → Level Phi；部分走廊 → Level 4 / 27；下水道 → Level 34；霓虹灯增多 → Level 699。
- 与 Wikidot 冲突处：Fandom 称**该层级找不到门**，出口在**管线夹层(crawlspaces)**里，且**仍带电的线缆会造成重伤**。
- 来源：[Fandom Level 2 @ Wayback](https://web.archive.org/web/20260717063551/https://backrooms.fandom.com/wiki/Level_2)（直连 403）。

## 5. 可用于关卡机制的官方细节

- **串联电路灯网**：破坏一盏灯或一根线，**同一片 3×3 至 6×6 灯网会整体熄灭**（脚注 5）。
- **大停电（Blackout）**：全层级断电两年；管道内容物积聚 → 爆裂／泄漏／腐肉般恶臭；少数紫外应急灯亮起；部分门重新开启，可进入**虚空房间**（无限大、无声无光、极易迷失致死）。
- 机器几乎不运转，只发出"quiet internal whirring noises, as if the machines are faulty"；管道输送流体、电力、气体，偶尔是固体。
- 归档版补充：**43 °C+ 的高温出现在机器噪音最大处（通常走廊尽头）**；通风管内有粘稠黑色液体；管内噪音来自 Crawler。
- 中文术语参考（[后室中文维基 Level 2](https://backrooms-wiki-cn.wikidot.com/level-2)）：noclip = **切出**（进入用**切入**）、The Frontrooms = 前厅、The Hub = 枢纽、anomalous doors = 异常门径、the blackout = 大停电。

## 6. 本作 Level 2 现状与差距

| 项 | 本作实现 | 与官方对比 |
| --- | --- | --- |
| Level 3 出口 | **热区切出**：隧道 C 东端死路（格 39–41 / row 22）的过热管道夹层，站进热池约 3 s 切出，期间缓降血量（最低保留 20），猎犬不入热区（2.2 m 站位余量） | 机制一致：官方"反常高温区切出"就在这里（原文把热区放在机器最响的走廊尽头）；区别是官方目标层级为 Level 127，本作接到 Level 3。原走廊解锁门（`level-two-door-level-three`）已移除——它的门框/门扇碰撞体是猎犬卡在出口的原因 |
| Level 4 出口 | `level-two-door-level-four`（格 37,26，"OFFICE" 门） | 一致（"oftentimes even Level 4"） |
| 枢纽出口 | `level-two-hidden-hub-door`（格 31,9）。平时是 B1 支路尽头的一堵**混凝土墙**（发丝细缝 + 地面 B/A 踏板），按 **科乐美秘籍码** 顺序走完 10 步走廊才唤醒：墙板下沉、门显形、门头亮起专属符号；唤醒前没有提示也无法交互 | 一致：官方原文说枢纽入口的位置"不成文、只存在于成员间的传闻中"，脚注直接点名**"跟随一串按科乐美秘籍码排列的走廊"**。本作把这句脚注做成了实际玩法 |
| Level 1 返回门 | **已按需求移除** | 偏离：官方现行版把 Level 1 列入最常用的三个出口门之一；归档版写作"偶尔回到 Level 1" |
| 死路门 | A2/A3/B1/B2/C1 支路尽头的混凝土门（仅有门体，不参与通行） | 一致（"most of these doors are locked or lead to dead ends"） |
| 环境暖区 | 另外三处地面暖区（`addLevelTwoFloorHeat`：格 29,13 / 22,22 / 12,6）只有视觉表现，不触发切出 | 与上面的出口热区区分开：官方只把"反常变热"的地方当切出点，普通暖区保持纯氛围 |
| 灯网串联 / 大停电 | 未实现（现有灯具只有亮度抖动与 brownout） | 可作为后续机制点 |
